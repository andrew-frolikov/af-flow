AF Flow

A personal, fully local macOS dictation app. Not a product.

Hold a key, speak in English, Russian or Ukrainian (including mixed), release, and cleaned up text lands at the cursor in whatever app is frontmost. Everything runs on device.

This is a private fork of Ghost Pepper (MIT), built for one person and never distributed. There is no download, no release, and no support. Build it from source or do not run it.
